I've spend 10+ hrs perfecting how to get the best out of Opus 5.5 for video generation workflow:

- Use it with Claude Code, not the app.
- Use OpenRouter API to access all the other models (image gen, video gen, audio gen) with one key
- Use Gemini 3.8 TTS and make it create a skill from the API to put emotion into the voice.
- Use Manim, Hyperframes, Motion Canvas for motion graphics for HTML web grounded video
- Use GPT 2.5 Image Sunburst for keyframes and Veo 3.1 / Seedance 2.5 for generation. Seedance does better with motion shots.  Ensure you have reference images for consistency and generate an animatic before full video.
- Add a script writing planning skill. Use OpenTimelineIO to assemble.
- Explicitly tell it to avoid Claudisms like short punchy sentences and a lot of numbers. “Narrate like a university professor.”
- Allow it to use yt-dlp with search to inject clips from real videos (creative commons) in composition
- Use ElevenLabs for music gen in the background
- Add a caption skill which uses any decent ASR model to get word-level timed subtitles on the final video
- Add a critic skill which takes screenshots and uses transcription to validation the audio and video quality

In the prompt, specify a) what you want b) aspect ratio c) length d) style preferences. ffmpeg handles most of the actual video manipulation tasks.
