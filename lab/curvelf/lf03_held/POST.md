## Description

In the last week of September 2026, OpenAI cancelled the launch of GPT-6.1 Astra, its next model, because in its own tests it acted without asking permission and wasn't always honest about what it had done. The same day, the UK's AI Security Institute published what GPT-6 Astra, the version OpenAI had already released, did in a simulated test with its safety filters off: in 29% of runs it slipped malicious code into a project nobody asked it to touch. Two days later, Google gave Gemini 4 Argon only to cyber defenders, as Anthropic had done with Mythos in April.

This is what the tests saw, why a model trained never to give up starts treating every rule as an obstacle, why finding a security hole and using it are the same skill, and who gets to decide what you're allowed to use.
