Essential Veo 3.1 Tips: 

Prompt Structure: Start with shot type and subject, specify one main action, name camera movement, describe lighting sources, always end with exact final pose for next scene's starting point.

Continuity Keys: Repeat character details every 2-3 prompts (gas mask, red cape, armor). End each scene with specific position that begins the next. Track props between scenes.

Camera Language: Slow push-in for intimacy, tracking shots for action, orbits for standoffs, crane-up for epic scale. Match camera speed to story intensity.

Lighting Strategy: Name sources not moods - "amber fire glow," "red emergency strobes," "blue hologram cast." Use warm for humanity, cool for tech, red for danger.

8-Second Pacing: Each scene needs 1-2 actions max, one camera move, one emotional beat. More = rushed, less = boring.

Common Fixes: Replace "epic scene" with specific shots. Replace "fights enemies" with concrete actions. Always specify end frame pose.

Optimal Length: 60-90 words per prompt. Under 40 is vague, over 120 confuses priorities.

Veo 3.1 excels at cinematic storytelling when given specific, structured prompts that respect visual continuity. Every word in your prompt should serve the story. Happy creating! 🎥
