# Start here

Read `HANDOFF.md` first (its top section is the current state and what to do next), then `STUDIO.md` (map of every
channel, engine and page) and `AUTOMATION.md` (the 50-channel plan). Work on branch `claude/funny-newton-gd9w8v` only. The standing rules are at the end of the
handoff's top section. `lab/motion` has its own `AGENTS.md` for Remotion work.

Before scripting, storyboarding or prompting any film or Short, read `CRAFT.md` (house rules: authorship vs YouTube's
inauthentic-content policy, narration style, banned looks, process gates, packaging). Before any upload, run the
`film-critic` skill. After each film, add what the critic caught to CRAFT.md's "Learned on our films".

Growth loop: `GROWTH.md` (pick ideas from the weekly radar, make to CRAFT, measure with YouTube Analytics at 48 h / 7 d and write lessons into CRAFT "Learned"). Scheduled: Monday 09:00 weekly review + radar (local scheduled task `weekly-growth-review`).

**Quality bar (owner, 16 Oct 2026): aim for the best possible result, never "good enough".** Before any production task, find
the proven best method (evidence: benchmarks, stars, creator consensus, our own analytics), prefer native/free tools
(Blender, After Effects, Remotion, local models) over paid third-party generators when quality is equal or better, and
run an independent critic on every output. If a result could clearly be better, say so and fix it before showing it.
