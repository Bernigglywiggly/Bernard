# Fehmarnbelt pilot: picture credits and rights log

Compiled 2026-10-08/09. 22 files kept, all used in `script.py`. Every file came from Wikimedia Commons; the licence column
is the licence tag on the Commons file page (read through the Commons API `extmetadata` fields `LicenseShortName` /
`UsageTerms` on 8 Oct 2026). No press, agency, stock or owner (Femern A/S) media-library pictures are used: Femern's
own photographs are not released under a free licence.

**Share-alike:** six files are CC BY-SA (marked SA below). If one of them is cropped, graded or animated, the result is
an adaptation and that adapted picture must be offered under the same licence. Safest handling: show SA pictures
unaltered apart from scaling, credit them on screen and in the description with the licence name, and state in the
description that those frames remain CC BY-SA. If that is not acceptable for the channel, drop the six SA files; the
film still has 16 CC BY / public-domain photographs (above the 12 the script needs, after re-pointing 6 beats).

## How the files were obtained

- All from upload.wikimedia.org by `curl`. Originals wider than 4,200 px were taken as Commons' own 3,840 px rendering
  (the largest it serves); smaller originals are untouched. `puttgarden_site_2022.jpg` is a crop of the 35 MB original.
- Licence, author and date were read from the Commons API for each file, not from search snippets. A human should open
  each source page once before upload: a Commons tag is the uploader's statement, not a guarantee.
